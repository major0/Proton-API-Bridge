# Roadmap
This is the basic project roadmap for the Proton-API-Bridge project.

## Version 1.x
Version 1.x was developed using a simple [Markdown][] file to track the project.
See the [Legacy Roadmap](/docs/LegacyRoadmap.md) for details.

## Version 2.x
The Version 2.x roadmap is being developed using the [issue tracker](../issues)
and [milestons](../milestones). All tasks in the roadmap are opened as an issue
and discussions regarding each task are tracked accordingly.
